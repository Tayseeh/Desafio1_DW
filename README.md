# Controle de estacionamento

Projeto front-end feito com HTML, CSS e JavaScript, sem frameworks.

## Como executar

Abra o arquivo `index.html` em um navegador. Se necessário, use um servidor estático local para carregar os módulos JavaScript.

## Telas

- **Vagas cadastradas:** mostra reservas fictícias e permite remover uma reserva.
- **Vagas disponíveis:** mostra os números das vagas sem reserva.
- **Cadastro de reserva:** recebe os dados do veículo, proprietário, apartamento, bloco e vaga. Ao salvar, mostra os dados no console e exibe uma confirmação.

O código está organizado em Model, View e Controller. Os dados de exemplo e os cadastros feitos durante o uso ficam apenas em memória; ao recarregar a página, voltam os dados fictícios.
